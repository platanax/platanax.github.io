# Description
Cette page a pour vocation de rendre simple l'accès au contenu **Presse** mis à disposition par la BNF, en remplacement de [EasyBNF](https://easybnf.fr/) qui ne fonctionne plus.

Les liens mis à disposition dans la page sont une sélection personnelle parmi les ressources accessibles sur le site de la BNF via un **Pass BnF lecture illimité**.

Cette page est un simple HTML qui peut être auto-hébergé n'importe où.

# Liens
* L'ensemble des ressources disponibles sont listées sur cette page : https://www.bnf.fr/fr/ressources-electroniques-de-presse
* Le pass est disponible sur abonnement ici : https://www.bnf.fr/fr/pass-bnf-lecture-culture
